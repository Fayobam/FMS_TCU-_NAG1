Awaiting controller

ATF-only is an experimental manual mode using the shared ATF circuit and speed sensors. It requires no TRRS or CAN selector. Paddle shifts require a confirmed forward gear while moving; stopping requires fresh identification. Unknown range uses de-energized hydraulic operation, without electronic reverse-selection protection.

Secure the vehicle in P/N with the engine off before changing mode. The ATF circuit must read open. Bench validation is required before road use.

Controller signals

Pulse status is reported independently for each shaft; no pulses can mean stopped or missing, and N3 can legitimately stop in some gears. The ATF circuit shares the P/N contact: an open contact and disconnected wiring can look alike. The main temperature display and chart show live measurements only. Battery and current readings require configured sensing hardware.

SESSION DIAGNOSTICS

Snapshot age includes time held on the controller plus time since browser receipt; network transit time is not measured. Queue skips count individual client send attempts. Firmware counters reset at boot; browser counters reset when this page reloads.

Connection preferences

Automatic mode tries remembered networks in priority order. Fallback access stays available during station reconnection.

Remember a network

Up to five networks. Passwords are never returned to the browser. Settings changes may disconnect this session; commands are never replayed after reconnect.
